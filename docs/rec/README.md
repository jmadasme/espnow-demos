# rec/ — video explicativo

Este directorio contiene el video asciinema de **ESP-NOW sin infraestructura** y el reproductor
que se usa en la página del proyecto.

- `espnow-demos.cast`: grabación original (asciicast v2).
- `espnow-demos.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:06. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
